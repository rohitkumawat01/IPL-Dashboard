# IPL-Dashboard
# 🏏 IPL Analytics Dashboard | Power BI

## 📊 Project Overview

The **IPL Analytics Dashboard** is an interactive and data-driven **Power BI project** designed to analyze and visualize Indian Premier League (IPL) statistics across multiple seasons.

The dashboard transforms raw IPL data into meaningful visual insights related to **team performance, batting, bowling, season-wise trends, match outcomes, toss decisions, captains, and player achievements**.

The main objective of this project is to make complex IPL statistics easy to understand through an interactive dashboard that allows users to explore historical performance and identify important trends.

---

## 🎯 Project Objectives

* Analyze IPL team performance across different seasons.
* Identify the most successful IPL teams.
* Analyze batting and bowling performances.
* Compare team and player statistics.
* Understand the impact of toss decisions on match outcomes.
* Analyze season-wise IPL performance and trends.
* Identify important player achievements such as **Player of the Match, Orange Cap, and Purple Cap**.
* Build an interactive and user-friendly business intelligence dashboard.

## ▶️ How to Use

1. Download or clone this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open `IPL Dashboard.pbix`.
4. If required, update the dataset/file paths in Power Query.
5. Click **Refresh** to load the latest data.
6. Use the dashboard navigation, slicers and filters to explore the analysis.

> **Note:** Power BI Desktop is required to open and interact with the `.pbix` file.
